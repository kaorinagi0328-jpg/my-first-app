# クラス向けカラオケ採点アプリ - MVP設計 (2026-10-25)

## 目的
- クラスで公開して使う
- 楽譜を読み込み、選択したパートを歌い、音程が合っているか確認できる

## 大事な割り切り（MVP）
PDF/写真の楽譜をそのまま自動で読む（OMR）は精度が低く重いので、MVPでは対象外。
代わりに、ブラウザで確実に読める形式を「楽譜の読み込み」とする:
1. MusicXML (.musicxml / .mxl) - MuseScore（無料）で楽譜を作って書き出せる。パート分けも保持される
2. MIDI (.mid) - トラック/チャンネルをパートとして扱える
3. サンプル曲を最初から内蔵 - ファイルなしでもすぐ試せる（例: かえるの合唱など著作権フリー曲）

PDF対応は将来、先生がMuseScoreに変換してから読み込む運用でカバーする。

## 画面の流れ
1. 楽譜ファイルを選ぶ（またはサンプル曲）
2. パートを選ぶ（ソプラノ/アルト/主旋律など、ファイル内のパート一覧から）
3. 練習モード:
   - お手本再生（選択パートをピアノ音で再生、他パートは小さく再生も可）
   - テンポ調整、開始小節の指定（繰り返し練習用）
4. 歌うモード:
   - カウントイン後に伴奏/お手本が流れ、マイクで歌う
   - 画面はピアノロール: 横に流れる目標の音符ブロックの上に、自分の声の音程ラインを重ねる
   - 合っている音は緑、ずれた音は赤でその場で見える
5. 結果:
   - 総合点（100点満点）、音ごとの正解/ずれ（セント単位）
   - ずれが大きかった箇所のリスト、もう一度ボタン

## 採点の仕組み
- マイク音声は端末内だけで処理し、サーバーに送らない（子どもの声を外部送信しない）
- 音程検出: Web Audio API + 自己相関/YIN系（pitchy ライブラリ想定）。周波数→MIDIノート番号+セントに変換
- 曲の再生時刻と同期して、各音符の区間で歌声の中央値の音程を取る
- 判定目安: ±50セント以内=◎、±100セント以内=○、それ以外=×。音ごとの一致率を平均して100点満点
- オクターブ違いは子ども/大人の声域差を考慮し、設定で「オクターブ違いは正解扱い」も選べるようにする

## 技術構成（GitHub Pagesで公開）
- 静的Webアプリ: Vite + TypeScript（Reactは使わず軽量に始める案も可）
- 配置: GitHubリポジトリ → GitHub Actions → GitHub Pages でクラス向けURLを公開
- 音源再生: Web Audio API（ピアノ音はシンセ生成、外部音源ファイル不要）
- 保存: なし（成績は端末内のみ表示。必要なら後から先生用にCSV書き出し追加）
- 対応端末想定: 学校のChromebook / iPad / PC のChrome・Safari。マイク許可が必要
