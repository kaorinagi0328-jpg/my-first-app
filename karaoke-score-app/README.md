# karaoke-score-app

クラスで使うカラオケ採点アプリ。楽譜（MusicXML）を読み込み、パートを選んで歌うと、音程が合っているかその場で見えて、最後に点数が出ます。

- 声は端末の中だけで処理します。サーバーに録音を送りません。
- GitHub Pages で公開して、Chromebook / iPad / PC のブラウザから使えます。

## 使い方

1. ページを開く
2. 「サンプル曲で試す」か、MusicXML ファイル（.musicxml / .xml）を選ぶ
   - 楽譜は MuseScore などで MusicXML に書き出せます
3. パートを選ぶ
4. 「お手本を聞く」でメロディを確認
5. 「歌って採点」でマイクを許可して、カウント後に歌う
6. ピアノロールで緑＝合っている、赤＝ずれている箇所を確認し、合計点を見る
